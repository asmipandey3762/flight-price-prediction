How it was built

Project pipeline

Step 1

Data cleaning

Dropped index and flight code columns, removed 2,213 duplicates and 2,226 duration outliers (IQR method).

Step 2

EDA

Class, airline, days left, stops, departure time and route-wise analysis with charts.

Step 3

Encoding

Class as 0/1, stops as 0/1/2, one-hot encoding for airline, cities and time slots.

Step 4

Modelling

Linear, Ridge, Decision Tree, Random Forest and XGBoost compared on R², MSE, RMSE and MAE.
